# Production Release

This skill describes the complete, comprehensive, and exhaustive end-to-end production release process that should be followed every single time without exception when shipping a new version of the software to production. It is intentionally extremely detailed so that nothing is ever left to chance or to memory.

It is very important to understand that releasing software to production is a serious and consequential activity, and that this skill exists precisely in order to make sure that the process is followed carefully, consistently, and completely on every single occasion without any exceptions whatsoever.

## Overview of the process

The overall process consists of the following numbered phases, each of which is described in exhaustive detail in its own dedicated section further down below in this document:

1. Preflight checks
2. Version bump
3. Changelog
4. Build artifacts
5. Automated tests
6. Staging deploy
7. Manual approval
8. Production deploy
9. Post-deploy verification
10. Rollback
11. Post-release tasks
12. Communication
13. Dependency audit
14. Security scan
15. Database migration
16. Feature flag review
